# RootSign v0.1.5 — SDK micro-batching + MCP proxy

RootSign **v0.1.5** bundles the two design-partner-driven capabilities from the Pre-Phase-2 sprint — **SDK micro-batching** and a **framework-agnostic MCP proxy** — plus a HiTL correctness fix.

## Highlights

### 🚀 SDK micro-batching — `BufferedIngestClient` (ADR-009)
An opt-in wrapper around any ingest client that buffers `ACTION_RECORD`s in memory and flushes asynchronously, so a long, tool-heavy pipeline never pays a per-call ingest round-trip. Enable with `ROOTSIGN_BUFFERED=true` (the factory wraps the transport for you) or wrap explicitly.

Buffering is **selective**: only auto-authorized actions are buffered — HiTL, decision, and session records pass through synchronously, so approvals and hash-chain ordering are never deferred. Three flush triggers (size cap, 500 ms background loop, explicit/close), with FIFO retry on transient failures. `session()` flushes before `SESSION_CLOSE`.

```python
from rootsign import BufferedIngestClient, LocalIngestClient

async with BufferedIngestClient(LocalIngestClient(db=db)) as client:
    async with rootsign.session(agent_id=agent_id, client=client) as ctx:
        ...  # buffered; flushed before SESSION_CLOSE
```

### 🔌 MCP proxy — protocol-level provenance (ADR-010)
RootSign can now intercept at the [Model Context Protocol](https://modelcontextprotocol.io) layer instead of a per-framework adapter. Point your agent's MCP client at the RootSign proxy and every `tools/call` becomes a tamper-evident `ACTION_RECORD` — **any MCP-compatible agent is instrumented with zero framework code**.

```bash
pip install rootsign[mcp]
```

```python
from rootsign.mcp.proxy import create_proxy_app

app = create_proxy_app(upstream_url="http://your-mcp-server:8001/mcp", client=client, ctx=ctx)
# uvicorn-compatible ASGI app; tools/call recorded + forwarded, other methods pass through.
```

Reuses the existing SDK machinery: redaction-before-hash (ADR-006) and HiTL via `require_approval=True` (ADR-007) — a gated proxy pauses before the call reaches the upstream server. Lazy imports keep the core SDK importable without the `mcp` extra.

### 🛠 Fixes
- **HiTL input coercion (#12)** — the HiTL path now coerces tool input through `_to_json_safe`, matching the auto path, so non-JSON-safe arguments no longer break the pending-action insert or desync `input_hash`.
